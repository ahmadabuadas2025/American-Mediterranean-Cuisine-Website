# Media prompts and asset log

Every photo and video on the site is currently an **AI illustration** generated with Higgsfield (October 2026). They are marked `illustrative: true` in the content files. The brief asks for real photography of the actual food, packaging and setups wherever possible, so treat these as stand-ins until real photos exist.

**To replace an image:** upload the real photo in the CMS (`/admin`) on the matching menu item, package, gallery or settings entry, and set "Photo is a placeholder or AI illustration" to off. For best performance, a developer can also drop the original into `media-src/` with the same file name and run `node scripts/process-media.mjs` (creates AVIF and WebP at 640/1024/1600 px).

**Shared style suffix** (appended to every prompt): warm natural window light, ivory linen, soft olive-green ceramics, terracotta accents, shallow depth of field, realistic Mediterranean catering food, no text, no logos, no faces.
